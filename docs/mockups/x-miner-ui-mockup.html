Console colors map to standard 24-bit ANSI escapes (Windows Terminal, conhost on Windows 10+, every Linux terminal); a --no-color flag falls back to plain text for logs and HiveOS. Share lines use cockpit words: LOCK (accepted), MISS (rejected), JOB, FEE. Plain words stay alongside them so the log reads clearly to new users.
